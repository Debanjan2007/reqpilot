# ReqPilot

**A lightweight, developer-first desktop API client.**

ReqPilot is an open-source desktop application designed to simplify API testing and debugging. It aims to provide a clean, intuitive, and distraction-free experience for developers working with HTTP APIs.

## ✨ Features

Planned for v1.0.0:

- Send HTTP requests (GET, POST, PUT, PATCH, DELETE, etc.)
- Configure request headers, query parameters, and body.
- Support API authentication.
- Inspect response body, headers, status codes, and response time.
- Organize requests into collections.
- Maintain request history.
- Clean and minimal desktop interface.
- Local-first experience.

## 🛠️ Tech Stack

- Electron
- React
- TypeScript
- Node.js
- SQLite

## 🚧 Development Status

ReqPilot is currently under active development. The initial release (v1.0.0) focuses on delivering a reliable and intuitive manual API testing experience.
